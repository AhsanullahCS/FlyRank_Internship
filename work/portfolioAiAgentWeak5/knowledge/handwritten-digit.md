# Handwritten Digit Recognition

## Project Overview

Handwritten Digit Recognition is a deep learning computer vision project that recognizes handwritten digits.

## Dataset

The project uses the MNIST dataset.

MNIST contains:

- 60,000 training images
- 10,000 test images
- 28 × 28 pixel grayscale images
- 10 classes representing digits 0 through 9

## Technology

The project uses:

- Python
- PyTorch
- Deep Learning
- Computer Vision
- MNIST

## Objective

The objective is to train a neural network to classify images of handwritten digits into the correct digit class.
