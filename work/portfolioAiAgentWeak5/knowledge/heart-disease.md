# Heart Disease Prediction

## Project Overview

Heart Disease Prediction is a machine learning classification project focused on predicting whether a patient is likely to have heart disease based on available features.

## Goal

The goal is to build and evaluate machine learning models for heart disease classification.

## Workflow

The project included:

- Exploratory Data Analysis
- Data preprocessing
- Feature preparation
- Model training
- Model evaluation
- SMOTE
- Threshold tuning

## Class Imbalance

SMOTE was used as part of the project to address class imbalance in the training data.

## Model Evaluation

The project evaluated model performance using classification metrics.

Known final test results:

Accuracy: 0.8554

Precision: 0.3039

Recall: 0.5187

F1 Score: 0.3833

## Threshold Tuning

Threshold tuning was used to explore the trade-off between different classification outcomes.

## What I Learned

The project provided practical experience with exploratory data analysis, preprocessing, class imbalance, SMOTE, model evaluation, and classification threshold tuning.
